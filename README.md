# 명자뉴스 채널 (mom-news-app)

어머님을 위한 김포 날씨(오늘 + 5일 예보)·미세먼지 + 오늘의 뉴스(사회·경제·정치·미국·연예) + 유튜브 인기 요리 영상 웹앱입니다.
서버가 필요 없는 **순수 HTML/CSS/JS 정적 앱**이라 GitHub Pages, Netlify, Vercel 같은
정적 호스팅에 폴더째 올리면 그대로 동작합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 뼈대 (상단 이름·글자 크기, 탭, 날씨 카드, 유튜브 배너, 뉴스/요리 영역) |
| `styles.css` | 큰 글씨·고대비 디자인, 글자 크기 3단계(보통/크게/아주 크게) |
| `app.js` | 날씨·미세먼지·5일 예보 호출, 뉴스 불러오기/캐시/1시간 자동 갱신, 유튜브 요리 영상, PWA 등록 |
| `videos.js` | 추천요리 유튜브 영상 15개 (영상 ID는 oEmbed로 실제 재생 확인) |
| `recipes.js` | 예전 내장 집밥 레시피 33가지 (지금 화면에서는 쓰지 않고 자료로만 남겨 둠) |
| `manifest.json` | PWA 매니페스트 (`name`/`short_name`: 명자뉴스 채널) |
| `sw.js` | 서비스 워커 (화면은 캐시, 뉴스·날씨는 새로 받고 실패하면 캐시) |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` | 앱 아이콘 |
| `preview.png` | 휴대폰 화면(390×844) 미리보기 스크린샷 |

## 데이터 출처

* **김포 날씨**: Open-Meteo Forecast API — `latitude=37.6153`, `longitude=126.7156`
  (키 필요 없음, CORS 허용)
* **미세먼지·초미세먼지**: Open-Meteo Air Quality API (`pm10`, `pm2_5`)
  * 미세먼지(PM10): 0~30 좋음 / 31~80 보통 / 81~150 나쁨 / 151~ 매우나쁨
  * 초미세먼지(PM2.5): 0~15 좋음 / 16~35 보통 / 36~75 나쁨 / 76~ 매우나쁨
* **뉴스**: 연합뉴스 RSS (전체/사회/경제/정치/국제/연예) — 연합뉴스 RSS는 CORS 헤더가 없어
  브라우저에서 직접 못 읽습니다. 그래서 `rss2json.com`(무료, 키 불필요)을 1순위로,
  `api.allorigins.win`·`api.codetabs.com`·`api.cors.lol` 프록시를 동시에 호출해
  가장 먼저 도착한 응답을 씁니다. 모두 실패하면 안내 문구와 `다시 불러오기` 버튼,
  그리고 연합뉴스 해당 면 바로가기를 보여 줍니다.

## 동작 방식

* 기사 12건을 먼저 보여 주고 `기사 더 보기`로 이어서 봅니다. 카드를 누르면 원문이 새 창으로 열립니다.
* 기사 사진은 제목 옆에 작게(약 90×69px) 붙어 한 화면에 기사가 더 많이 보입니다.
  `loading="lazy"`로 불러오고, 사진이 없거나 깨지면 카테고리 기본 그림으로 바뀝니다(`onerror` 대체).
* 받아온 뉴스는 브라우저에 1시간 저장해 두고, 화면을 열어둔 채로도 1시간마다(`setInterval`)와
  화면으로 돌아올 때(`visibilitychange`) 새 뉴스를 자동으로 받아 옵니다. 새로 받지 못하면 저장된 기사를 보여 줍니다.
* **스포츠 기사는 어느 탭에도 나오지 않습니다**: 연합뉴스 기사 주소 끝 분야코드(`0007`/`1007`)와
  제목 키워드(야구·축구·농구·프로야구·우승 등)로 걸러냅니다.
* **미국 탭**은 연합뉴스 국제면 RSS에서 미국·워싱턴·백악관·트럼프·연준·월가·뉴욕 등 미국 관련 기사만 골라 보여줍니다.
  `전체` 탭에서도 미국 외 다른 나라 단독 기사는 걸러내고, 미국 주요 뉴스는 남깁니다.
* 글자 크기 선택은 브라우저에 기억됩니다.
* 추천요리: 유튜브 인기 요리 영상 15개(백종원·김대석 셰프TV·1분요리 뚝딱이형·이보은 레시피)를
  실제 유튜브 썸네일 카드로 보여 줍니다. 검색은 내장 영상을 걸러 주고, 검색어가 있으면
  `유튜브`·`만개의레시피` 검색 버튼이 함께 나옵니다.
* 홈 화면에 추가: 안드로이드 크롬 `⋮ → 홈 화면에 추가`, 아이폰 사파리 `공유 → 홈 화면에 추가`.

## 로컬에서 확인하기

```bash
cd mom-news-app
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 (휴대폰 화면으로 보려면 개발자도구 기기 모드 390×844)
```

## 배포하기 (GitHub Pages 예시)

1. 저장소에 `mom-news-app` 폴더를 올립니다.
2. Settings → Pages → Branch를 `main`, 폴더를 `/mom-news-app`(또는 루트)로 지정합니다.
3. `https://<아이디>.github.io/<저장소>/mom-news-app/` 주소로 열립니다.
4. 어머님 휴대폰에서 그 주소를 열고 `홈 화면에 추가`를 하면 앱처럼 쓸 수 있습니다.

## 참고 (뉴스 프록시 한도)

`rss2json.com` 무료 사용은 한 시간에 60회, 처음 변환하는 피드 수에 제한이 있습니다.
앱은 카테고리별로 한 번만 받아 20분간 저장해 두므로 일상 사용에는 충분하지만,
처음 며칠 안에 여러 번 새로고침하면 일시적으로 `뉴스를 불러오지 못했어요`가 나올 수 있습니다.
그때는 1~2분 뒤 `다시 불러오기`를 누르면 됩니다.
