# 명자채널 (mom-news-app)

어머님을 위한 김포 날씨(오늘 + 5일 예보)·미세먼지 + 여러 언론사 오늘의 뉴스(사회·경제·정치·미국·연예) + 코뿔소 TV 최신 영상 + 유튜브 인기 요리 영상 웹앱입니다.
서버가 필요 없는 **순수 HTML/CSS/JS 정적 앱**이라 GitHub Pages, Netlify, Vercel 같은
정적 호스팅에 폴더째 올리면 그대로 동작합니다.

## 데이터 출처

* **김포 날씨**: Open-Meteo Forecast API — `latitude=37.6153`, `longitude=126.7156`
  (키 필요 없음, CORS 허용)
* **미세먼지·초미세먼지**: Open-Meteo Air Quality API (`pm10`, `pm2_5`)
  * 미세먼지(PM10): 0~30 좋음 / 31~80 보통 / 81~150 나쁨 / 151~ 매우나쁨
  * 초미세먼지(PM2.5): 0~15 좋음 / 16~35 보통 / 36~75 나쁨 / 76~ 매우나쁨
* **뉴스**: 연합뉴스·SBS·동아일보·한겨레·매일경제·머니투데이 RSS — 이들 RSS는 CORS 헤더가 없어
  브라우저에서 직접 못 읽습니다. 그래서 `rss2json.com`(무료, 키 불필요)을 1순위로,
  `api.allorigins.win`·`api.codetabs.com`·`api.cors.lol` 프록시를 이어서 시도합니다.
  * 피드 주소 뒤에 받는 시각(`?sb=<밀리초>`)을 붙여 **rss2json·중계 서버의 오래된 캐시를 피합니다.**
    (이 표시가 없으면 rss2json이 몇 시간 전 기사를 계속 돌려줘 뉴스가 늦게 보였습니다.)
  * 그래도 90분 넘게 묵은 응답이 오면 그 통로는 버리고 다음 통로를 시도합니다.
  * 모두 실패하면 안내 문구와 `다시 불러오기` 버튼, 해당 면 바로가기를 보여 줍니다.

## 동작 방식

* 기사 12건을 먼저 보여 주고 `기사 더 보기`로 이어서 봅니다. 카드를 누르면 원문이 새 창으로 열립니다.
* 기사 사진은 제목 옆에 작게(약 90×69px) 붙어 한 화면에 기사가 더 많이 보입니다.
  `loading="lazy"`로 불러오고, 사진이 없거나 깨지면 카테고리 기본 그림으로 바뀝니다(`onerror` 대체).
* 받아온 뉴스는 브라우저에 저장해 두고 **5분마다** 새 속보를 다시 받아 옵니다(`setInterval`, 1분마다 확인).
  앱을 다시 열거나 화면으로 돌아오면(`visibilitychange`·`focus`) **3분**이 지났을 때 바로 새로 받고,
  `↻ 새로고침` 버튼은 저장된 것을 건너뛰고 곧바로 최신 기사를 가져옵니다. 새로 받지 못하면 저장된 기사를 보여 줍니다.
* 모든 기사는 **발행 시각(pubDate) 내림차순 — 최신 속보가 맨 위**로 옵니다(BBC식으로 섞지 않음).
* **전체 탭은 사회 뉴스 위주**입니다: 연합뉴스·SBS·동아일보·한겨레의 사회면 피드를 넣어 받고,
  최신순으로 훑되 사회 기사 3건마다 다른 분야(경제·정치·연예·미국) 1건만 섞습니다(약 75%가 사회).
  제목이 `[속보]`·`[긴급]`·`[단독]`으로 시작하면 빨간 `속보` 표시가 붙습니다.
* **스포츠 기사는 어느 탭에도 나오지 않습니다**: 연합뉴스 기사 주소 끝 분야코드(`0007`/`1007`)와
  제목 키워드(야구·축구·농구·프로야구·우승 등)로 걸러냅니다.
* **미국 탭**은 연합뉴스 국제면 RSS에서 미국·워싱턴·백악관·트럼프·연준·월가·뉴욕 등 미국 관련 기사만 골라 보여줍니다.
  `전체` 탭에서도 미국 외 다른 나라 단독 기사는 걸러내고, 미국 주요 뉴스는 남깁니다.
* 글자 크기 선택은 브라우저에 기억됩니다.
* **삼성전자·SK하이닉스 시세 카드**는 두 종목을 가로 2열 타일로 놓아 높이를 예전의 절반쯤으로 줄였습니다
  (현재가와 등락률은 크게 유지). 좁은 휴대폰·'아주 크게' 글씨에서는 글자 크기를 조금 줄여 두 칸에 한 줄로 들어갑니다.
* **상단 뉴스 탭**(전체·사회·경제·정치·미국·연예·추천요리)을 누르면 맨 위로 가지 않고 그 구역
  ('오늘의 뉴스' / 요리 목록) 시작으로 부드럽게 내려갑니다. 고정 헤더 높이 + 8px을 빼서 제목과 첫 기사가
  헤더에 가리지 않습니다. 기사·사진이 늦게 붙어 위치가 어긋나면 1.8초 동안 한 번씩 다시 맞춥니다.
* 추천요리: 백종원·김대석 셰프TV·1분요리 뚝딱이형·쿡피아(이보은)·만개의레시피·하루한끼·영자씨의 부엌·
  이연복의 복주머니·식탁일기·승우아빠, 이렇게 유명 요리 채널 10곳의 유튜브 공개 RSS를 받아
  최신 영상을 실제 썸네일 카드로 보여 줍니다. 채널마다 돌아가며 골라 **1시간(60분)마다 다른 조합**으로
  바뀌고(화면에 열어둔 채로도 정시마다 자동), 화면 목록·채널 목록을 브라우저에 저장해 두었다가
  막히면 그대로 보여 줍니다. 검색창 대신 요리 종류 칩(국·찌개/반찬/볶음·구이/찜·조림/밥·면)만 남겼습니다.
* 홈 화면에 추가: 안드로이드 크롬 `⋮ → 홈 화면에 추가`, 아이폰 사파리 `공유 → 홈 화면에 추가`.

## 로컬에서 확인하기

```bash
cd mom-news-app
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 (휴대폰 화면으로 보려면 개발자도구 기기 모드 390×844)
```

## 배포하기 (GitHub Pages 예시)

1. 저장소에 `mom-news-app` 폴더를 올립니다.
2. Settings → Pages → Branch를 `main`, 폴더를 `/mom-news-app`(또는 루트)로 지정합니다.
3. `https://<아이디>.github.io/<저장소>/mom-news-app/` 주소로 열립니다.
4. 어머님 휴대폰에서 그 주소를 열고 `홈 화면에 추가`를 하면 앱처럼 쓸 수 있습니다.

## 참고 (뉴스 프록시 한도)

`rss2json.com` 무료 사용은 한 시간에 60회, 처음 변환하는 피드 수에 제한이 있습니다.
앱은 카테고리별로 한 번만 받아 20분간 저장해 두므로 일상 사용에는 충분하지만,
처음 며칠 안에 여러 번 새로고침하면 일시적으로 `뉴스를 불러오지 못했어요`가 나올 수 있습니다.
그때는 1~2분 뒤 `다시 불러오기`를 누르면 됩니다.
